# Review every non-spec living document in one impact step

- Date: 2026-10-08
- Supersedes: —

ADRs, glossary, architecture, roadmap, and README each need attention on a significant change. Giving each its own artifact would stretch the workflow from five steps to nine, and long workflows get skipped. A single `impact.md` asks one question of each document and accepts "Not affected: reason" as an answer. The cost is that the step is a checklist rather than five deliverables, so its quality rests on the reasons given.
